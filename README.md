## Build workflow

This project writes generated Typst output to `build/`.

- `Compile Book` builds `main.typ` to `build/main.pdf`.
- `Compile Current File` builds the active file to `build/<filename>.pdf`.
- `Watch Book` watches `main.typ` and updates `build/main.pdf` on changes.

The `build/` folder is ignored by Git, so source files and assets stay cleanly versioned.

Tip: Open `build/main.pdf` in your PDF viewer and enable auto-reload, then run `Watch Book` for live updates while writing.

## Using VS Code tasks

Task definitions are in `.vscode/tasks.json`.

Run tasks in VS Code:

1. Open the Command Palette (`Cmd+Shift+P`).
2. Run `Tasks: Run Task`.
3. Pick one of these tasks:
	- `Compile Book`: Compile `main.typ` to `build/main.pdf`.
	- `Compile Current File`: Compile the currently active Typst file to `build/<filename>.pdf`.
	- `Watch Book`: Recompile `main.typ` automatically on file changes.

You can also use `Terminal -> Run Task...` from the menu.
For quick builds, `Cmd+Shift+B` runs the default build task (`Compile Book`).
